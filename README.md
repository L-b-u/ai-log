# AI 学习记录

📚 个人 AI 学习笔记仓库，记录每日学习内容、工作流方法、工具与实践项目。

## 目录结构

```
.
├── 01-工作流/    # AI 辅助研发工作流、可复用方法论
├── 02-理论/      # AI / 机器学习 / LLM 理论知识
├── 03-工具/      # 常用工具、配置、使用技巧
├── 04-项目/      # 实践项目与动手实验
└── 05-资源/      # 优质资料、论文、链接收藏
```

## 使用说明

- 每个主题文件夹内按需建子目录，保持结构清晰
- 每天的学习内容整理成一个 Markdown 文件，放入对应文件夹
- 每次改动完成后提交一个 Git commit，便于追踪与回滚
